Your PC. No Limits.

VeltOS is a desktop operating system that works the way Windows 11 users are used to: Start, the taskbar, File Explorer, Settings and an app store, right where you expect them. It brings its own apps, a modern installer and support for Windows programs through Wine. Free, open source and built on Debian.

Familiar from the first minute

Everything where you expect it

No new habits to learn. VeltOS follows the layout and the little details of Windows 11, and keeps the speed, security and freedom of Linux.

Start, taskbar, search

A centred taskbar with live window previews, Start with pinned apps and recommendations, search as you type, Task View with virtual desktops, and the right-click menus you know.

File Explorer

Tabs, Home, This PC, the Recycle Bin, Properties, zip files and Windows drives — and the same file dialogs in every program.

One Settings app

Wi-Fi, Bluetooth, display, sound, accounts, apps, privacy and updates on pages you already know, in your language.

VeltOS Store

Thousands of free apps and games from Debian's signed archive, installed and updated with one click.

Office and Mail

Word, Excel and PowerPoint start screens on LibreOffice, with Microsoft's file formats by default, and VeltOS Mail in the look of Outlook.

Windows programs

Double-click an .exe or .msi: VeltOS installs it with Wine and adds it to Start and Settings. Not every program works, and VeltOS tells you when one does not.

Automatic Repair

If VeltOS fails to start twice in a row, a repair screen opens by itself, with Startup Repair, Safe mode, Command Prompt and the details of what went wrong.

Secure by default

Software comes only from signed Debian archives or is built from VeltOS' own sources, with Secure Boot, AppArmor and disk encryption that asks for the password at start-up, like BitLocker.

Make it yours

Light and dark mode, eight themes with their own wallpapers, an accent colour that follows you into every VeltOS app — and Windows 11's animations.

Windows programs

Double-click. Install. Find it in Start.

VeltOS opens Windows installers and programs with Wine in one Windows environment, like the single C: drive of a PC. Installed programs appear in Start and in Settings, where you can uninstall them as on Windows.

  1. 1
    Open the .exe or .msi

    VeltOS reads the file's name, publisher and icon, then shows what it will do.

  2. 2
    Install

    The program's own installer runs. Wine Mono and Gecko come pre-installed, so nothing is downloaded.

  3. 3
    Use it like any app

    It appears in Start and in Settings › Apps; on graphics cards with Vulkan, games use DXVK.

Honest note: Wine does not run every Windows program, and it is not a security sandbox — run only programs you trust.

Tested on every build

Every package runs its unit tests while it builds, and the image checks itself before it is written. Each ISO then boots in QEMU with UEFI and BIOS, with checks for the desktop, crashes and start-up times.

Light by design

Every background service has to earn its place; start-up and memory use are measured for each ISO.

Questions

Frequently asked

Is VeltOS Windows?

No. VeltOS is a Linux system built on Debian. It looks and behaves like Windows 11 so that you feel at home, but it is a different operating system and is not affiliated with Microsoft.

Will my Windows programs run?

Many do, through Wine; some do not, and some run with problems. VeltOS never promises that every program works — it shows you what happened, and for many tasks it offers its own apps instead.

Does it cost anything?

No. VeltOS is free and open source, and so is the software it is built from.

Is it ready for daily use?

Not yet: version 0.1 is a pre-alpha for testing. Try it in a virtual machine or on a spare PC and report what you find on GitHub.

Can I try VeltOS in a virtual machine?

Yes, that is how VeltOS is tested. Give the virtual machine 4 GB of memory and a 25 GB disk; UEFI and BIOS both work, and turning on 3D acceleration makes the desktop smoother. On a Windows PC with Hyper-V on (WSL2, Docker Desktop), VirtualBox can freeze a virtual machine until a key is pressed — a known VirtualBox bug; QEMU/KVM is not affected.

Where do updates come from?

From Debian's signed archives, installed through VeltOS Store and Settings. VeltOS' own packages are built from its source code on GitHub.

Which languages does it support?

English and Turkish, everywhere VeltOS has its own windows. Debian's and KDE's parts are available in many more languages.

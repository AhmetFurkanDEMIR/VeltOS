The first public release of VeltOS: a Debian 13 desktop in the look of
Windows 11, with its own apps.

- **Windows 11's desktop:** taskbar, Start, search, Quick Settings, Task
  View, notifications, light and dark mode with an accent colour.
- **VeltOS' own apps:** File Explorer, Settings, Store, Mail, Office (on
  LibreOffice), Photos, Media Player, PDF Reader, Notepad, Calculator,
  Clock, Calendar, Weather, Maps, Camera, Snipping Tool, Task Manager,
  Disk Management, Archive, VeltOS AI.
- **Windows programs** through Wine: double-click a `.exe` or `.msi`.
- **Drivers:** NVIDIA's driver from Debian with one button (Graphics Cards).
- **Installer:** a Windows 11 style setup with disk encryption.

VeltOS'un ilk herkese açık sürümü: Windows 11 görünümünde, kendi
uygulamalarıyla bir Debian 13 masaüstü.

- **Windows 11 masaüstü:** görev çubuğu, Başlat, arama, Hızlı Ayarlar,
  Görev Görünümü, bildirimler, vurgu rengiyle açık ve koyu mod.
- **VeltOS'un kendi uygulamaları:** Dosya Gezgini, Ayarlar, Mağaza, Mail,
  Office (LibreOffice üzerinde), Fotoğraflar, Medya Oynatıcı, PDF Okuyucu,
  Not Defteri, Hesap Makinesi, Saat, Takvim, Hava Durumu, Haritalar,
  Kamera, Ekran Alıntısı Aracı, Görev Yöneticisi, Disk Yönetimi, Arşiv,
  VeltOS AI.
- **Windows programları** Wine ile: `.exe` veya `.msi` dosyasına çift
  tıklayın.
- **Sürücüler:** NVIDIA sürücüsü tek düğmeyle Debian'dan (Grafik Kartları).
- **Kurulum:** disk şifrelemeli, Windows 11 tarzı bir kurulum.
